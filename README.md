# 經營室

先看懂客人在哪裡漏，再挑一兩格補起來。

把經營室裝進你自己的 Claude 或 ChatGPT（Codex）。它會先上網看一下你的店，再一題一題問你，大部分用選的。聊著聊著，旁邊就長出一張你的脈絡地圖：客人怎麼走、哪裡在漏、一個月大概少賺多少、最值得先做的三件事。

目前是測試版（v11-preview）。

## 三步開始

1. 打開 **Claude 桌面版的 Code 分頁**，或 **ChatGPT 桌面版裡的 Codex**，開一個新的本機工作，資料夾選「文件」。
2. 貼上這一句：

   > 請幫我安裝 https://github.com/Nelsen0717/business-room ，讀裡面的「開始.md」，帶我開始。一次只問我一件事，不要叫我操作終端。

3. 回答助手的問題。聊到第一分鐘，你的第一張圖就會出現。

之後想再打開，對同一個助手說「打開我的經營室」就好。要改什麼、補什麼，都在對話裡說。

## 你會拿到什麼

- **一張會長大的脈絡地圖**：我理解的你、你的成功公式、客人怎麼走（六格）、時間花在哪、三個機會、附近的對象、手上的資料、下一步。
- **最大的洞一個月大概漏多少**：用哪個算式、哪些條件都點得開；洞可能有兩個，先補最大的。
- **你的本命星座**：訪談完，助手挑幾件你真的說過、做過的事，替你的店連成一個星座、取個名字、配一句話和一個顏色。每一間經營室長得都不一樣，但每一顆星都點得開、看得到出處。
- **第一份能直接用的內容**：例如一則回訪訊息、一張介紹小卡、一份附近公司的名單條件。
- 沒有自己的資料，也可以先用三家示範店試：一人美甲工作室、社區便當店、手工皂網店。

## 需要什麼

- Claude（Pro 以上）或 ChatGPT（免費也能用，額度比較少，建議 Plus）。訪談和本命星座請用各家最新、最強的模型，問得更準、畫得更像你。
- 電腦上的桌面版 App。
- Python 3.10 以上。沒有的話，助手會帶你安裝。

## 你的資料

全部存在你電腦的「文件／我的經營室」，我們不收你的經營資料。唯一會連到我們的地方是兌換課程碼：助手把課程碼送到課程包服務，換回課程包，就這樣。要不要接 Google、Notion 等服務，由你自己決定、自己登入。
