# 經營室

先看懂自己的生意，再挑一格做順。

把經營室裝進你自己的 Claude 或 ChatGPT（Codex），跟它聊一位你最滿意的客人。它會幫你畫出客人從哪裡來、在哪一格掉走，算出最痛那一格一個月大概漏掉多少，並打開一個只屬於你的經營室。

目前是測試版（v10-preview）。

## 三步開始

1. 打開 **Claude 桌面版的 Code 分頁**，或 **ChatGPT 桌面版裡的 Codex**，開一個新的本機工作，資料夾選「文件」。
2. 貼上這一句：

   > 請幫我安裝 https://github.com/Nelsen0717/business-room ，讀裡面的「開始.md」，帶我開始。一次只問我一件事，不要叫我操作終端。

3. 回答助手的問題。聊完，它會幫你打開經營室。

之後想再打開，對同一個助手說「打開我的經營室」就好。

## 你會拿到什麼

- **一張六格地圖**：找客、迎客、成交、口碑、養客、回客。只標跟你有關的格，其他格寫清楚為什麼先不做。
- **最痛那一格一個月大概漏掉多少**：這是情境估，會寫出用了哪個算式、哪些條件。
- **第一份能直接用的內容**：例如一則回訪訊息、一張介紹小卡、一份附近公司的名單條件。
- 沒有自己的資料，也可以先用三家示範店試：一人美甲工作室、社區便當店、手工皂網店。

## 需要什麼

- Claude（Pro 以上）或 ChatGPT（免費也能用，額度比較少，建議 Plus）。
- 電腦上的桌面版 App。
- Python 3.10 以上。沒有的話，助手會帶你安裝。

## 你的資料

全部存在你電腦的「文件／我的經營室」。我們這邊沒有伺服器，也不收你的資料。要不要接 Google、Notion 等服務，由你自己決定、自己登入。
