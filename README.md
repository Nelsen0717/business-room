# 小二

讓客人來，也讓客人回。

小二是住在你自己的 Claude 或 ChatGPT（Codex）裡的經營夥伴。第一天它花大約四十五分鐘訪談你，旁邊那一頁「經營室」就跟著長出你的生意：你的招牌、你的客人、目的與目標、六格。訪談最後，小二先給你一版它自己的樣子：名字、顏色和樣子。之後每天早上，它排好三件事；晚上幫你對帳、調整明天。

目前是測試版（v14.0-preview.1）。

## 三步開始

1. 打開 **Claude 桌面版的 Code 分頁**，或 **ChatGPT 桌面版裡的 Codex**，開一個新的本機工作，資料夾選「文件」。
2. 貼上這一句：

   > 請幫我安裝 https://github.com/Nelsen0717/the-two-by-n ，讀裡面的「開始.md」，帶我開始。一次只問我一件事，不要叫我操作終端。

3. 回答小二的問題。第一分鐘，旁邊就會出現你的第一張圖。

之後想再打開，對同一個小二說「打開我的經營室」。要改什麼、補什麼，都在對話裡說。

## 你會拿到什麼

- **看得到全貌的經營室**：我理解的你、你的招牌、三種客人和各自去哪找、目的與目標的達成率、六格、存下來的。每個數字都點得開出處。
- **先從哪一邊開始**：333 法則。很久沒來的客人超過名單的三分之一，先叫回頭客；沒有，就先找新客。名單少於 20 位，比例不準，一律先找新客。程式會算給你看。
- **每天三件事**：小二早上排好，每件寫清楚什麼時候、在哪、對誰，附草稿。做完按一下「做了」，再點結果。
- **晚上對帳**：你接了信箱或日曆，小二自己看寄出與回覆，更新離目標多遠，調整明天。每週一次盤點，看哪一招有效。
- **你的本命星座**：訪談完，小二挑幾件你真的說過、做過的事，替你的店連成一個星座、取個名字、配一句話和一個顏色。每一顆星都點得開、看得到出處。
- **你的小二**：每個人的小二都不一樣。訪談完，小二照你的店和你說話的樣子，先提一版名字、顏色和樣子，你說好就用。之後想改，名字、顏色、樣子在經營室的「你的小二」點一下就換；想改它怎麼叫你、怎麼說話，直接跟它說。
- **模組**：把一種做法做成一塊積木，像「名錄開發」「舊識問候」「評論邀請」。小二照你的情況挑幾塊組起來，一次最多三個在跑，新的先試兩週，兩週後一起看要不要留。它也會在你一再需要同一件事的時候，替你寫一塊只屬於你的。
- **找客人的門路**：小二找附近的公司、店家和聚點時，不靠內建搜尋猜關鍵字。台灣的資料它直接打開官方清冊、Google 地圖和社群頁面來看，查到的存起來，下次不重查。
- 沒有自己的資料，也可以先用示範店試：一人美甲工作室、社區便當店、手工皂網店。

## 需要什麼

- Claude（Pro 以上）或 ChatGPT（免費也能用，額度比較少，建議 Plus）。訪談和本命星座請用各家最新、最強的模型，問得更準、畫得更像你。
- 電腦上的桌面版 App。
- Python 3.10 以上。沒有的話，小二會帶你安裝。
- 早上、晚上的例行用你那一家的排程功能，電腦和 App 要開著才會跑。沒開著，到點就不會跑；你叫小二「開門」或「打烊」時，它會先補做沒做到的那一段。只是打開經營室那一頁，小二不會知道。

## 你的資料

全部存在你這台電腦上、你選的那個「我的經營室」資料夾，我們不收你的經營資料。安裝時小二會先問你要放在哪裡，因為有些電腦的「文件」會同步到雲端，客人資料也會跟著上去。唯一會連到我們的地方是兌換課程碼：小二把課程碼送到課程包服務，換回課程包，就這樣。要不要接 Google、Notion 等服務，由你自己決定、自己登入。

## 想走得更遠

小二是《獲客減法實戰課》帶著你用的工具。上課會拿到一組課程碼，跟小二說「我的課程碼是……」，每一格在台灣做得通的做法就會出現在經營室裡。

公開版附上模組的名字和說明，小二也認得它們，會照名字和每天的原則帶你做。14 個模組的完整做法（為什麼有效、怎麼做、今天的事長這樣、兩週後怎麼判斷、紅線）在課程包裡，換了課程碼才會出現。怎麼找新客、怎麼叫回頭客、怎麼接上各種工具，也都在課程裡。
